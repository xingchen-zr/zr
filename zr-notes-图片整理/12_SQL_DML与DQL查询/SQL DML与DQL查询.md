# SQL DML与DQL查询

图片编号：094, 095, 096, 097, 098, 099, 100, 101, 102, 103, 104, 105, 106, 107

## 主题说明

这一组是添加、修改、删除、条件查询、聚合、分组、排序、分页和执行顺序。

## 必要解释

- DML 负责数据变化：`insert` 新增、`update` 修改、`delete` 删除。
- DQL 负责查询：`select ... from ... where ...` 是最核心结构。
- 聚合函数用于对一列数据整体计算，例如 `count`、`avg`、`max`、`min`。
