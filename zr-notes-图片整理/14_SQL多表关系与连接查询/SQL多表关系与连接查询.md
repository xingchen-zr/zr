# SQL多表关系与连接查询

图片编号：129, 130, 131, 132, 133, 134, 135, 136, 137, 138, 139, 140, 141

## 主题说明

这一组是多表关系、一对多、一对一、多对多，以及内连接、外连接、自连接、union。

## 必要解释

- 多表关系是数据库建模的重点，例如部门和员工通常是一对多。
- 连接查询用于把多张表的数据按条件组合起来。
- `union` 是把多次查询结果合并为一个结果集。
