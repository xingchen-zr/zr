# 模块与常用库

图片编号：051, 052, 053, 054, 055, 056, 057, 058, 059, 060, 061, 062

## 主题说明

这一组是 import、from import、as 起别名、主模块、math、datetime、json 和自定义工具模块。

## 必要解释

- `import 模块名` 是导入整个模块，使用时通常写 `模块名.函数名`。
- `from 模块 import 函数` 是只导入模块中的某个对象。
- `json` 很重要，当前你的成绩系统就是 JSON 文件读写。
