图片编号：001, 002, 003, 004, 005, 006, 007

## 主题说明

这一组主要是 Python 入门阶段的基础概念，包括字符编码、字符串拼接、f-string、基本数据类型转换、索引和切片。

## 必要解释

- 字符编码可以先理解为“字符和数字之间的对应规则”，学 Python 时重点知道字符串在程序中是 `str` 类型。
- f-string 的作用是把变量嵌入字符串，例如 `f"我叫{name}"`。
- 索引和切片是后面处理列表、字符串、文件内容时都会反复用到的基础。
