# Python容器类型

图片编号：008, 009, 010, 011, 012, 013, 014, 015, 016, 017

## 主题说明

这一组是 list、tuple、dict、set 等容器类型，重点是理解它们分别适合存什么数据。

## 必要解释

- `list` 适合保存一组有顺序、可修改的数据。
- `tuple` 和列表类似，但通常表示不希望被随意修改的数据。
- `dict` 是键值对结构，适合像成绩系统里的 `姓名 -> 成绩`。
- `set` 适合去重和集合运算。
