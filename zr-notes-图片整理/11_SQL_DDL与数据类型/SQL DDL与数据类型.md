# SQL DDL与数据类型

图片编号：084, 085, 086, 087, 088, 089, 090, 091, 092, 093, 121, 122, 123, 128

## 主题说明

这一组是建表、字段类型、表结构修改、数据库操作、约束案例和非空/唯一约束。

## 必要解释

- DDL 主要负责创建、修改、删除数据库结构，例如 `create table`、`alter table`、`drop table`。
- 字段类型要按数据特点选择：姓名可用 `varchar`，身份证可用 `char(18)`，日期可用 `date`。
- 约束用于限制数据质量，例如非空、唯一、主键、外键。
